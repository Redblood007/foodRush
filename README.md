# FoodRush Android Starter

A Kotlin + Jetpack Compose starter for a food delivery app. Includes a home screen, sample restaurant listings, search, category filters, and an in-memory cart.

## Open in Android Studio
1. Extract the ZIP file.
2. In Android Studio choose **Open** and select the `FoodRush` folder (the folder containing `settings.gradle.kts`).
3. Allow Gradle sync to finish and install any requested Android SDK components.
4. Create/start an Android emulator from **Tools > Device Manager**, or connect a phone with USB debugging enabled.
5. Press **Run**.

## Current limitations
- Restaurant/menu data is demo data in the app source.
- Cart is held in memory and resets when the app process restarts.
- Login, backend, checkout, payment processing, delivery tracking, restaurant dashboard, and admin panel are not yet implemented.
- No APK has been built in this environment; build and test it in Android Studio.
